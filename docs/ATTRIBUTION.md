# Artwork sources

- `icons/api-gateway.svg` and `icons/lambda.svg`: official **AWS Architecture
  Icons**, distributed by [`aws-icons` 3.3.0](https://www.npmjs.com/package/aws-icons).
  Original service names: Amazon API Gateway and AWS Lambda. Original artwork
  and colors are preserved; the diagrams resize and embed the SVGs.
  See [AWS Architecture Icons and usage guidance](https://aws.amazon.com/architecture/icons/).
  The package's MIT notice is included at `icons/LICENSE.aws-icons`.
- `icons/auth0.svg`: Auth0 logo mark from
  [Simple Icons](https://github.com/simple-icons/simple-icons/blob/develop/icons/auth0.svg)
  (CC0). The logo is reproduced unmodified in black for identification.
- Browser glyph: original drawing using the laptop/desktop convention from
  diagram-design's `primitive-icons.md` (Tabler-style line work).
- Otter, shell and reed illustrations: original SVG artwork in
  `web/app/marks.tsx`, covered by this repository's MIT license.
- Layout/export workflow follows
  [diagram-design](https://github.com/cathrynlavery/diagram-design), MIT.
  The app's palette and system-font stacks replace the skill's default skin;
  see `style-guide.md`.

AWS and Auth0 names/logos remain their owners' trademarks. Their presence
identifies the services in this example and does not imply endorsement.
